## Standing rules
- **Git flow:** trunk-based. PRs are squash-merged, with green CI before merging. Review every agent PR before merging:
  - no inline suppressions (`type: ignore`, `pyright: ignore`, `noqa`, `pragma: no cover`)
  - no attribution trailers or session links in commits or PR bodies
  - never the words "Perch" or "purge"
- **Changelogs:** `CHANGELOG.md` is generated by git-cliff; never edit it by hand. The docs sites regenerate it on every build.
- **Markdown:** a blank line before every top-level list. Nested items are indented two spaces, three under `1.`, with no blank line before them. `make docs` runs `scripts/check_site.py`, which fails if a list renders as text.
- **Git hooks:** `make install` in a worktree points the repo's shared git hooks at that worktree's venv. Re-run `uv run pre-commit install --hook-type pre-commit --hook-type commit-msg` from the main checkout before removing a worktree.
- **Never:**
  - publish to PyPI or tag without asking
  - change repo, Pages or PyPI settings
  - touch the read-only repos
  - read `services/litellm-proxy/.env`
  - remove containers you didn't create
